# Server Logic Tools user guide

This is the documentation home for **Logic Starter**, **Server Objects**, and **Logic Inspector** — the three pages of the Server Logic Tools Power Platform ToolBox (PPTB) tool. It points you to the right document, organised by the four [Diátaxis](https://diataxis.fr/) quadrants so you can find what you need by intent rather than by title.

[README](https://github.com/RyanMakesAndBreaksStuff/PowerPage-ServerLogic/blob/main/README.md)

## Tutorials

Learning-oriented lessons that take you from a blank start to a working result.

- [Create your first starter](https://github.com/RyanMakesAndBreaksStuff/PowerPage-ServerLogic/blob/main/docs/tutorials/create-your-first-starter.md) — produce a server handler, a matching client call, and a permission checklist, then export and deploy them.

## How-to guides

Problem-oriented instructions for a specific task.

- [Generate and adapt a starter](https://github.com/RyanMakesAndBreaksStuff/PowerPage-ServerLogic/blob/main/docs/how-to/generate-and-adapt-a-starter.md) — choose a recipe, set the name, method, and client, edit the handler, review readiness, and download the package.
- [Browse and insert Server Objects](https://github.com/RyanMakesAndBreaksStuff/PowerPage-ServerLogic/blob/main/docs/how-to/browse-and-insert-server-objects.md) — search the `Server.*` catalogue and insert a sample into the current Starter handler.
- [Inspect a site's server logic](https://github.com/RyanMakesAndBreaksStuff/PowerPage-ServerLogic/blob/main/docs/how-to/inspect-a-sites-server-logic.md) — scan a Power Pages site, review each file's findings, and export a report.
- [Troubleshoot](https://github.com/RyanMakesAndBreaksStuff/PowerPage-ServerLogic/blob/main/docs/how-to/troubleshoot.md) — symptoms and what to check.
- [Build and load the tool from source](https://github.com/RyanMakesAndBreaksStuff/PowerPage-ServerLogic/blob/main/docs/how-to/build-and-load-from-source.md) — developer setup, build, release gate, and loading the tool in PPTB.
